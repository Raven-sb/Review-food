Web demo giúp bạn khám phá quán ăn ngon dựa trên điểm đánh giá. Dữ liệu mẫu mang tính minh họa; chuyển sang chế độ Google Maps API để xem dữ liệu thực tế.

Nguồn dữ liệu

Dữ liệu mẫu được biên soạn theo cách Google Maps hiển thị đánh giá. Để lấy dữ liệu thật, nhấn biểu tượng ⚙ và nhập Google Places API key.

Lấy dữ liệu từ Google Maps

Nhập Google Places API key đã bật Places API (New) để tải các quán có điểm từ 4.0 trở lên theo từng thành phố.

⚠️ Key nhập ở đây nằm ở phía client. Hãy tạo key riêng và giới hạn theo HTTP referrer trong Google Cloud, kèm giới hạn chỉ dùng Places API.

Chưa có key? Xem hướng dẫn trong README.md của dự án.
